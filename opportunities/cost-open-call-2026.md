# COST Open Call 2026

**Kind:** network call  
**Priority:** P1  
**Status:** open  
**Submission window:** 2026-07-31 12:00 CEST — 2026-10-28 12:00 CET  
**Expected new Actions funded:** up to 80  
**Primary source:** https://www.cost.eu/funding/open-call-a-simple-one-step-application-process/

## Strategic role for EC

COST is primarily a **network-building instrument**, not a conventional R&D project grant. For EC that is a feature, not a weakness.

A well-designed COST Action could create a European research/practice network around topics such as:

- digital commons governance;
- machine-readable governance;
- open-source sustainability;
- data and IP governance;
- semantic interoperability;
- institutional design for shared digital infrastructure.

Potential working title:

> **European Network for Digital Commons Governance and Interoperability**

## Why this matters

EC's long-term power is not purely financial. A cross-European network can generate:

- research collaborators;
- future Horizon consortium partners;
- universities able to support doctoral/postdoctoral work;
- public-sector adopters;
- standards and policy relationships;
- scientific legitimacy;
- shared publications, workshops and training;
- access to additional national and EU funding.

## Decision test

EC should only attempt to propose an Action in 2026 if it can assemble a credible multi-country proposer network without distracting from higher-probability immediate funding.

Alternative strategy: join one or more existing COST Actions that overlap EC's fields and use them to build the relationships required for a stronger future proposal.

## Immediate actions

- [ ] Search current/new COST Actions for overlap with digital commons, data governance, semantic web, open science and digital sovereignty.
- [ ] Identify 10–20 plausible European proposers/partners.
- [ ] Estimate whether a 2026 submission is mature enough by early October.
- [ ] If not, prioritise joining relevant Actions and preparing a future proposal.
- [ ] Treat network composition as the central deliverable, not merely the application text.

## Anti-capture note

COST has low direct capture risk because it distributes networking capacity rather than buying control of EC's IP or roadmap. The main risk is opportunity cost: EC should not build a network merely to win an Action if the network itself lacks strategic value.
